# RAG 检索增强生成

## RAG 是什么

RAG（Retrieval-Augmented Generation）是一种让大模型基于外部知识库回答问题的技术。流程分三步：检索、增强、生成。

1. 用户提问
2. 从知识库检索相关文档片段
3. 将片段拼入 prompt，交给 LLM 生成答案

## 为什么需要 RAG

大模型存在几个局限：训练数据有截止日期，不知道最新信息；不知道私有文档和业务知识；可能产生幻觉编造事实。RAG 通过在推理时注入外部知识解决了这些问题。

## RAG 核心组件

- 文档处理：加载、切分（chunking）
- Embedding：将文本转为向量
- 向量数据库：存储向量并支持相似度检索
- 检索器：根据用户问题找到最相关的 chunk
- 生成器：基于检索结果生成最终答案

## Chunk 大小的影响

chunk 太小：丢失上下文，检索碎片化
chunk 太大：关键信息被稀释，可能超出 LLM 上下文窗口
通常 300-1000 token 是合理范围，具体取决于文档类型和应用场景
