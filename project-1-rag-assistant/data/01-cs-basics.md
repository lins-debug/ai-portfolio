# 数据结构基础

数据结构是计算机存储、组织数据的方式。常见的数据结构包括：

- 数组：连续内存存储，下标访问 O(1)，插入删除 O(n)
- 链表：非连续存储，访问 O(n)，插入删除 O(1)
- 栈：后进先出，用数组或链表实现
- 队列：先进先出，用于 BFS、消息队列等场景
- 哈希表：键值对存储，查找 O(1)，Python 中对应 dict
- 树：层次结构，二叉树是最常见的形式
- 图：由节点和边组成，用于社交网络、路径规划

## 时间复杂度

衡量算法效率的指标。常见量级从快到慢：O(1) > O(log n) > O(n) > O(n log n) > O(n²)。面试中能分析出时间和空间复杂度是基本要求。
