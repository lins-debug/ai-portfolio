# 数据库基础

## SQL 与 NoSQL

关系型数据库（MySQL、PostgreSQL）：结构化数据、ACID 事务、SQL 查询
NoSQL（MongoDB、Redis）：灵活 schema、水平扩展、适合非结构化数据

## 索引

索引是加速查询的数据结构。B+ 树索引最常用——叶子节点存数据，非叶子节点存键值。
索引不是越多越好：写入时需要更新索引，占用额外空间。

## 事务 ACID

原子性：要么全做，要么全不做
一致性：事务前后数据满足约束
隔离性：并发事务互不干扰
持久性：提交后数据不丢失

## Redis

内存键值数据库。常用场景：缓存、分布式锁、消息队列、排行榜。数据结构：String、Hash、List、Set、Sorted Set。持久化方式：RDB 快照 + AOF 日志。
