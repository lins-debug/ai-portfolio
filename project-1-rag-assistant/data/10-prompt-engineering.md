# Prompt Engineering 提示词工程

## 基本原则

清晰明确：指令要具体，不要模糊
提供上下文：给模型足够的背景信息
定义输出格式：JSON、列表、markdown 等
给示例：Few-shot 示例显著提升效果

## RAG 中的 Prompt 设计

关键点：告诉模型只基于提供的资料回答，明确说不知道时不要编造。典型结构：系统指令 → 上下文资料（带来源标注）→ 用户问题。

## 常见技巧

角色设定：你是一个严谨的 AI 助手
思维链：让模型逐步推理
约束输出：明确要求引用来源
处理边界：资料不足时明确告知用户

## 降低幻觉的策略

限定资料范围：只基于给定资料
要求标注来源：每个事实注明来自哪个文档
降低温度：temperature 设为 0-0.3
验证流程：关键回答做二次检索验证
