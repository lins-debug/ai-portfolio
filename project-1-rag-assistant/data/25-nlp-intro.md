# NLP 自然语言处理

## 基本任务

分词：将文本切分为最小语义单元。中文分词比英文复杂，常用 jieba、pkuseg。
词性标注：标注每个词的词性（名词、动词等），为后续分析提供特征。
命名实体识别：识别文本中的人名、地名、机构名。

## 文本表示

TF-IDF：词频-逆文档频率，衡量词在文档中的重要性
Word2Vec：将词映射为稠密向量，语义相近的词向量距离近
BERT：双向 Transformer 预训练模型，理解上下文

## 大模型时代的 NLP

GPT 系列模型让很多 NLP 任务从"专用模型训练"变成"通用模型 Prompt"。情感分析、文本摘要、翻译都可以用一个模型完成。但传统 NLP 知识帮助理解模型行为和调优。
