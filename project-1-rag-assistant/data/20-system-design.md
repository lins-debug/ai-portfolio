# 系统设计面试

## 常见题型

设计短链接系统、设计聊天应用、设计秒杀系统、设计分布式 ID 生成器。AI 岗位也常考：设计一个 RAG 问答系统、设计推荐系统。

## 答题框架

1. 明确需求：功能需求、非功能需求（QPS、延迟、一致性）
2. 估算规模：日活用户、数据量、带宽
3. 画架构图：自上而下，先整体后模块
4. 深入关键模块：数据库选型、缓存策略、负载均衡
5. 讨论扩展性：水平扩展、读写分离、数据分片

## 常用组件

负载均衡（Nginx、HAProxy）、缓存（Redis）、消息队列（Kafka、RabbitMQ）、数据库（MySQL 主从、分库分表）、对象存储（S3、MinIO）、CDN。

## 面试要点

不要求记住所有细节，重点是思路：为什么这样设计、trade-off 是什么、如何应对极端场景。画图比纯讲更清晰。
