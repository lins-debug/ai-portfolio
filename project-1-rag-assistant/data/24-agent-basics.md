# AI Agent 基础

## 什么是 Agent

Agent 是能自主决策、调用工具、多步执行的 AI 应用。和普通 LLM 调用的区别：LLM 只是输入输出，Agent 有思考和行动循环。

## 核心架构

1. 用户输入任务
2. LLM 分析任务，决定调用哪个工具
3. 工具返回结果
4. LLM 判断是否完成——未完则继续第 2 步
5. 输出最终结果

## 工具调用

Function Calling：在 LLM 请求中描述函数签名，LLM 返回要调用的函数和参数，代码执行后把结果返回 LLM。是 Agent 的核心能力。

## ReAct 模式

Reasoning + Acting：思考 → 行动 → 观察 → 思考的循环。Agent 说"我应该先搜索 XX"，然后调搜索 API，看到结果后决定下一步。这种显式推理提升了可解释性和准确性。
