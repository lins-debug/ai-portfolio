# AI 应用工程师技能图谱

## 必备技术栈

编程语言：Python 是绝对主力，了解 TypeScript/JavaScript 加分
后端框架：FastAPI（异步、高性能）、Flask（轻量、简单）
数据库：PostgreSQL、Redis、向量数据库（Chroma/Milvus）
DevOps：Docker、Git、Linux 基础、CI/CD

## LLM 相关技能

Prompt Engineering：设计清晰的指令和上下文，控制输出格式
模型选型：GPT-4o、Claude、DeepSeek 等，了解各模型特点
API 调用：OpenAI SDK、流式输出、函数调用
成本控制：缓存、合理选择模型、token 估算

## 知识库相关技能

RAG 全流程：文档处理 → 切分 → embedding → 检索 → 重排序 → 生成
文本处理：PDF/HTML/Markdown 解析，中文分词的坑
评估：检索命中率、答案 Faithfulness、端到端准确率

## 进阶方向

Agent：工具调用、多步骤推理、记忆管理
多模态：图片理解、语音交互
评估体系：构建测试集、自动化回归、A/B 测试
