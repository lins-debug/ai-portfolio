# 机器学习基础概念

## 监督学习

从带标签的数据中学习映射关系。包括：
- 分类：预测离散标签，如垃圾邮件检测
- 回归：预测连续值，如房价预测

## 过拟合与欠拟合

过拟合：模型在训练集上表现好但在测试集上差。原因：模型太复杂、数据太少。对策：正则化、增加数据、早停、dropout。

欠拟合：模型连训练集都拟合不好。对策：增加模型复杂度、特征工程、减少正则化。

## 交叉验证

将数据分成 k 份，每次用 k-1 份训练，1 份验证，轮换 k 次。取平均作为最终评估。常用 k=5 或 10。

## 常见评估指标

分类：准确率、精确率、召回率、F1、AUC-ROC
回归：MSE、MAE、R²
