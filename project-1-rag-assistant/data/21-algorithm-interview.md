# 算法面试高频题

## 数组与字符串

两数之和：用哈希表存目标差值，O(n)
最长无重复子串：滑动窗口
合并区间：先排序再合并
旋转数组查找：二分查找变种

## 链表

反转链表：迭代（三指针）或递归
环形链表检测：快慢指针
合并有序链表：归并思路
删除倒数第 N 个节点：双指针维护距离

## 动态规划

爬楼梯：f(n) = f(n-1) + f(n-2)
最长递增子序列：dp[i] = max(dp[j]) + 1 (j < i, nums[j] < nums[i])
背包问题：0-1 背包和完全背包

## 面试策略

先从暴力解开始，再优化。说清时间空间复杂度。边界条件要主动考虑。刷 LeetCode 按标签分类，先简单后中等。AI 岗位算法要求比纯后端低，但基础题必须熟练。
