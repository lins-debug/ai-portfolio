# 简历撰写指南

## 基本原则

一页纸（应届/1-3 年经验）。倒序排列经历。用数字量化结果：提升了多少、处理了多少数据、服务了多少用户。动词开头：设计、实现、优化、搭建。

## 项目经历写法

每个项目写 2-3 条 bullet point。格式：做了什么 + 用了什么技术 + 取得什么效果。

示例：
基于 FastAPI + Chroma 搭建 RAG 求职知识库，实现文档切分、向量检索和 LLM 答案生成，检索命中率 87.5%，平均响应 300ms

## 技能栏

不要堆砌关键词。按熟练度分层：精通 Python、FastAPI、OpenAI API；熟悉 Docker、PostgreSQL、Redis；了解 Kubernetes、MLflow。每个技能都要经得起面试深挖。

## 常见错误

职责描述而非成果描述、技术名词拼写错误、项目没有量化指标、个人信息过多（年龄、照片）、排版不一致。简历的第一读者是机器筛选系统，关键字匹配很重要。
