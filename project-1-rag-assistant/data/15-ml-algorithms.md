# 经典机器学习算法

## 决策树

通过一系列 if-else 规则做决策。优点：可解释性强、不需要特征缩放。缺点：容易过拟合。
随机森林：多棵决策树投票，每棵树用数据子集和特征子集训练，降低过拟合。

## SVM 支持向量机

寻找最大间隔超平面分类。核函数将低维数据映射到高维，使线性不可分变得可分。
常用核：线性核、RBF 核、多项式核。

## K-Means 聚类

无监督算法。步骤：选 K 个中心点 → 分配样本到最近中心 → 更新中心点为均值 → 重复直到收敛。
K 值选择用肘部法则（SSE 下降趋缓的点）。

## 梯度下降

优化算法，沿梯度反方向更新参数。批量梯度下降用全量数据，随机梯度下降每次一个样本。
mini-batch 是折中方案。学习率是关键超参数，太大不收敛，太小收敛慢。

## 特征工程

从原始数据中提取有用特征。包括：缺失值处理、类别编码、归一化、特征交叉、降维。
好的特征比复杂的模型更重要——这是机器学习中的共识。
