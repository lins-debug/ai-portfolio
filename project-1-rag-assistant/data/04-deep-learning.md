# 深度学习入门

## 神经网络基础

神经网络由多个层的神经元组成。每个神经元接收输入、加权求和、经过激活函数输出。核心组件：输入层、隐藏层、输出层、损失函数、优化器。

## 反向传播

计算损失函数对各层参数的梯度，从输出层向输入层逐层传播。配合梯度下降更新权重。这是神经网络学习的核心算法。

## 常见激活函数

ReLU：max(0, x)，计算快、缓解梯度消失，最常用
Sigmoid：1/(1+e^(-x))，输出 (0,1)，用于二分类输出层
Softmax：多分类输出层，输出概率分布
Tanh：(-1,1)，比 Sigmoid 均值为 0，收敛更快

## Transformer 架构

2017 年提出，彻底改变了 NLP 领域。核心是自注意力机制：每个词关注序列中所有词，计算相关性权重。优势是并行计算、长距离依赖捕捉。BERT、GPT 都是基于 Transformer 的变体。
