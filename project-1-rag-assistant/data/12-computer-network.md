# 计算机网络

## TCP 三次握手

1. 客户端发送 SYN
2. 服务器回复 SYN+ACK
3. 客户端回复 ACK

三次握手确保双方收发能力正常。两次不够——可能建立历史连接。

## HTTP 协议

HTTP/1.1：文本协议，队头阻塞问题
HTTP/2：二进制分帧，多路复用，头部压缩
HTTP/3：基于 QUIC（UDP），0-RTT 连接

## 状态码速查

2xx 成功：200 OK、201 Created
3xx 重定向：301 永久、302 临时
4xx 客户端错误：400 Bad Request、401 未授权、404 未找到
5xx 服务端错误：500 内部错误、502 网关错误、503 服务不可用

## DNS 解析

将域名转为 IP 地址。先查浏览器缓存 → hosts 文件 → 本地 DNS → 递归查询根域名服务器 → 顶级域 → 权威 DNS。CDN 利用 DNS 将用户引导到最近的节点。
