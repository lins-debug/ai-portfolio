# 软件开发基础

## 设计模式

单例：全局唯一实例，Python 中模块天然单例
工厂：封装对象创建逻辑
观察者：发布-订阅模式，事件驱动
策略：运行时切换算法

## 代码质量

DRY：不要重复代码
SOLID：五大设计原则（单一职责、开闭原则等）
KISS：保持简单
代码评审是保证质量的重要手段

## CI/CD

持续集成：每次提交自动运行测试和 lint
持续部署：通过测试后自动部署到生产
GitHub Actions 是最常用的 CI/CD 工具，.github/workflows 下配置 YAML

## 项目管理

敏捷开发：迭代交付，快速反馈。Scrum：Sprint 规划、每日站会、回顾。看板：可视化工作流。AI 项目需额外考虑：数据标注、模型效果的不确定性、实验管理。
